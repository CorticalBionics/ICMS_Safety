# Long-term safety and efficacy of intracortical microstimulation in humans
Repository to accompany paper "Long-term safety and efficacy of intracortical microstimulation in humans" published in Science Translational Medicine 2026.

Data can be found at: [https://dabi.loni.usc.edu/dsi/S8Q532OTAXMS](https://dabi.loni.usc.edu/dsi/LVUPBGAXILJ6).

Plotting requires the [ChartsWithCharles](https://github.com/CMGreenspon/ChartsWithCharles/releases/tag/v1.0) repository.
